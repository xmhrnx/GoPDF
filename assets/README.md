# Assets

| Path | What it is | License |
| --- | --- | --- |
| `icon.png` | App icon, 1024×1024, used for the window and every package | Project |
| `icons/` | Interface icons from Lucide | ISC, see `icons/LICENSE` |
| `fonts/` | Inter Regular, Medium and SemiBold | SIL OFL, see `fonts/OFL.txt` |
